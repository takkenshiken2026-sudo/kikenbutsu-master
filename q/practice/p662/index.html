危険物取扱者試験（乙種第4類） 実践演習 第662問（法令・制度）

問題

エタノール（指定数量400 L）を800 L、メタノール（指定数量400 L）を400 L貯蔵している。指定数量の倍数の合計として、正しいものはどれか。

選択肢

  1. （1） 3倍
  2. （2） 2倍
  3. （3） 4倍
  4. （4） 5倍
  5. （5） 6倍

正答

正答は （1） です。

解説

正解の理由

指定数量の倍数は品目ごとに数量を指定数量で割って合算する。エタノールは800÷400＝2倍、メタノールは400÷400＝1倍で、合計は2＋1＝3倍となる。エタノールもメタノールもアルコール類で指定数量は400 Lであるため、3倍が正しい。

他の選択肢

  • （2）

    2倍はエタノールの倍数だけを数えた値であり、メタノールの1倍を加えると合計3倍となるため誤りである。

  • （3）

    4倍はいずれかの倍数を多く見積もった値であり、エタノール2倍とメタノール1倍で合計3倍となるため誤りである。

  • （4）

    5倍は指定数量を小さく取り違えた場合などに近く、正しくは合計3倍となるため誤りである。

  • （5）

    6倍は各倍数を過大に見積もった値であり、エタノール2倍とメタノール1倍で合計3倍となるため誤りである。

危険物取扱者試験（乙種第4類） 実践演習 第327問（物性・化学）

問題

液体の一般的な特徴として、正しいものはどれか。

選択肢

  1. （1） 必ず燃えない。
  2. （2） 体積はほぼ一定だが、形は容器に応じて変わる。
  3. （3） 形も体積も必ず容器全体に広がる。
  4. （4） 必ず水に溶ける。
  5. （5） 形も体積も常に一定である。

正答

正答は （2） です。

解説

正解の理由

液体は、体積はほぼ一定だが、形は容器に応じて変わる。液体と気体の性質を区別する。液体の特徴である。試験では三状態の性質比較として問われやすい。

他の選択肢

  • （1）

    「必ず燃えない」について、燃える液体もある。ガソリンなど燃える液体もあり、必ず不燃ではない。

  • （3）

    「形も体積も必ず容器全体に広がる」について、気体の特徴に近い。気体は容器全体に広がる性質があり、液体とは異なる。

  • （4）

    「必ず水に溶ける」について、水に溶けない液体もある。水に溶けない液体も多く、必ず水溶液になるわけではない。

  • （5）

    「形も体積も常に一定である」について、固体の特徴に近い。形と体積が一定に近いのは固体の特徴である。

実践演習 · 火災・消火・漏えい

危険物取扱者試験（乙種第4類） 実践演習 第449問（火災・消火・漏えい）

問題

乾性油の自然発火を防ぐ管理として、適切なものはどれか。

選択肢

  1. （1） 火気の近くで乾燥させる。
  2. （2） 油を含んだ布を大量に積み重ねて放置しない。
  3. （3） 下水に流して処理する。
  4. （4） 袋に詰めて蓄熱させる。
  5. （5） 可燃性蒸気の中で喫煙する。

正答

正答は （2） です。

解説

正解の理由

乾性油を含んだ布は酸化熱が蓄積して自然発火するおそれがあるため、大量に積み重ねて放置しない。選択肢（2）「油を含んだ布を大量に積み重ねて放置しない」は、蓄熱を防ぐ管理である。油を含んだ布の蓄熱に注意。自然発火は火気なしでも起こり得る。

他の選択肢

  • （1）

    「火気の近くで乾燥させる」について、火気の近くは危険である。自然発火の危険があるため、火気の近くで乾燥させない。

  • （3）

    「下水に流して処理する」について、下水へ流してはならない。油を含む布等を下水へ流すと火災・環境汚染の危険がある。

  • （4）

    「袋に詰めて蓄熱させる」について、蓄熱のおそれがある。密閉・積み重ねは酸化熱の蓄積を助長し、自然発火のおそれがある。

  • （5）

    「可燃性蒸気の中で喫煙する」について、喫煙は危険である。火気は着火源となり、自然発火リスクとあわせて重大な危険がある。

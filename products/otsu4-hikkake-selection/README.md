# 商品B：ひっかけ読本（頻出ひっかけ厳選35・販売用マスター）

> v2改訂: 商品Aと同じ「読本」体裁（表紙・目次・章扉・明朝見出し・Noto CJKフォント）へ刷新。
> 内容（誤文→正しくは→見抜き方の35項目）は検証済みのまま、各章に導入文を追加。
> PDFは fonts-noto-cjk 導入環境で書き出すこと。

乙4の正誤問題で差がつく「ひっかけ文言」を、誤文→正しくは→見抜き方の3段で厳選。
赤シート対応（○正を隠して自己テスト）＋印刷/PDF対応の自己完結HTML。

## ファイル
- `index.html` … 商品本体（ブラウザで開く。答え隠しトグル＋A4印刷/PDF）
- `manuscript.md` … 制作方針・出典・検証ログ（正確性の証跡）
- `README.md` … 本ファイル（販売仕様）

## PDF化の手順
1. `index.html` をChromeで開く → 「🖨 印刷 / PDF保存」→ A4・背景ON → PDF保存
2. note／Kindle（KDP）／BOOTH にアップロード

## 販売設計（戦略メモより）
- **価格**：¥780（解説量で商品Aより単価を上げられる）

- `data/mistakes.csv` は重複テンプレ＋事実誤認（ガソリン＝特殊引火点 等）を含むため**丸写し禁止**
- 全35項目を一次/権威情報で事実確認して書き直し。出典でばらつく値は非掲載
- 「最新は公式確認」を明記

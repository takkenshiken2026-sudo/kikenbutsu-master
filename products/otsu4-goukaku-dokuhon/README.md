# 危険物乙4 合格読本（まとめ販売用マスター）

数字編・見抜く編・直前編・演習編を**1冊にまとめた合本**。これが販売する単位。
表紙・はじめに・目次・部扉・奥付を備え、**赤シート対応（数字・答えを隠す）＋印刷/PDF**の自己完結HTML。

## 構成
- 第1部 数字編（6章）… 指定数量・性状・法令数値を理解して覚える（背景・覚え方・出題例・ひっかけ）
- 第2部 見抜く編… 合否を分けるひっかけ35（誤文→正しくは→見抜き方）
- 第3部 直前・当日編… 3日プラン・最終確認・チェックリスト・当日ロジ・本番戦術
- 第4部 演習編… 解説付き問題27問（法令10・物化9・性消8）＝購入価値の中核

## 販売設計
- **これ1冊を単品販売**（¥1,480目安）。3冊バラ売りをやめ、合本＝まとめ販売に統一
- note／Kindle（KDP）／BOOTH にPDFで出品
- 単品構成品（products/otsu4-numbers-cheatsheet ほか）は素材・分冊配布用に温存

## PDF化
`index.html` をChromeで開く →「PDFで保存」→ A4。日本語フォント（Noto CJK／ヒラギノ等）が
入った環境で書き出すこと。当リポジトリ環境では `fonts-noto-cjk` 導入済み。

## 正確性ポリシー（最重要）
- 数値・制度・当日ルール・演習の正答は、消防試験研究センター・消防庁・自治体/危険物安全協会の
  公表資料で裏取り。CSV（numbers/mistakes）の既知の誤りは持ち込まない
- 演習27問はすべて検証済みの事実から作問。出典でばらつく値は非掲載

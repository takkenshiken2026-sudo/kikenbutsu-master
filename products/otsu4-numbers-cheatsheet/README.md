# 商品A：危険物乙4 数字の読本（販売用マスター）

マネタイズ戦略の「自社デジタル商品」第1弾。指定数量・引火点・比重・法令の頻出数値を
**「理解して覚える」読み物**として再設計した冊子。表紙・目次・章扉を備え、各章に
「背景（なぜその数字か）／覚え方の理屈／出題例／ひっかけ」を収録。通読でき、
直前は**赤シート対応（数字を隠す）＋印刷/PDF**で確認できる自己完結HTML。

> v2改訂: 単なる暗記シートから、明朝見出し＋本文解説の“読本”へ格上げ。
> フォントは Noto Serif/Sans CJK JP を使用（PDF書き出し時に必須。無い環境だと
> フォールバックで崩れるため、`fonts-noto-cjk` を導入してから生成すること）。

## ファイル
- `index.html` … 商品本体（ブラウザで開く。赤シート・印刷トグル付き）
- `manuscript.md` … 掲載数値の原稿・出典・検証ログ（正確性の証跡）
- `README.md` … 本ファイル（販売仕様）

## PDF化の手順（販売物の作り方）
1. `index.html` をChromeで開く
2. 「🖨 印刷 / PDF保存」→ 送信先「PDFに保存」／用紙A4／背景グラフィックON
3. 生成PDFを note／Kindle（KDP）／BOOTH にアップロード

## 販売設計（戦略メモより）
- **価格**：¥490（衝動買い域）／セット化時は「合格パック」に同梱
- **チャネル**：note（既存 `paidMockExam` と同じ導線）→ Kindle KDPで継続課金も
- **サイト内導線**：`記録・分析`で苦手判定が出た瞬間、および法令記事の文末から送客
- **差別化**：語呂・出る順・赤シート・オフラインは無料サイトにない有料価値

## 正確性ポリシー（最重要）
- `data/numbers.csv` は誤りを含むため**丸写し禁止**（灯油・軽油の指定数量200L→正1,000L 等）
- 掲載値は公式・一次情報＋権威ソースで裏取り済み。出典不一致の値（メタノール発火点等）は非掲載
- 制度・法令・手数料は改定され得るため、本文に「最新は公式確認」の注記を明記

## 公開範囲について
`products/` はサイトのビルド（`tools/prepare_public_site.sh` の明示allowlist）に含まれず、
GitHub Pagesには公開されない。有料商品マスターの置き場として安全。

# 関連試験への拡張 — 全体方向性（確定版）

最終更新: 2026-10-29 / ステータス: **方向性確定・実装着手前**

「乙4マスター」を、乙4を主軸にしたまま **危険物取扱者の試験ポータル** へ発展させる。
本書は実装に入る前の「確定した全体像」。各フェーズの実装はこの方針に従う。

---

## 1. 確定事項（意思決定サマリ）

| 論点 | 決定 |
|------|------|
| 最初に追加する試験 | **丙種・甲種** |
| サイトの持ち方 | **単一サイトに「試験軸」を追加**（別ドメイン・姉妹サイトにしない） |
| ブランド | **「乙4マスター」のまま。乙4を主軸**にし、丙種・甲種は「関連試験」として内包 |
| 設計の汎用化 | **消防設備士等の隣接資格まで**見込んで、試験を設定駆動の汎用エンティティとして設計 |
| ドメイン | 変更しない |
| 絶対条件 | **既存の乙4のURL・SEO評価を一切壊さない** |

## 2. 最終到達イメージ

```
乙4マスター（ブランド据え置き・乙4が主軸）
├─ 乙4         … 現行資産そのまま（URL・SEO評価を保持）
├─ 丙種        … 四肢択一・限定範囲・制度ページ＋性質消火
├─ 甲種        … 五肢45問・全類の性質消火20問＋受験資格
├─（将来）乙1/2/3/5/6 … 科目免除でのコンプリート動線
└─（将来）消防設備士 等 … 隣接資格。データモデルは最初から拡張可能にしておく
```

- 入口は乙4のまま。関連試験は「乙4の次の一歩」として二次導線で見せる。
- データモデル上は試験を汎用の `exam` エンティティとして扱い、将来の隣接資格追加でスキーマを作り直さない。

---

## 3. 確定した制度前提（丙種・甲種）

| 種別 | 問題数 | 科目内訳 | 形式 | 試験時間 |
|------|--------|----------|------|----------|
| 乙4（現行） | 35問 | 法令15／物化10／性質消火10 | 五肢択一 | 2時間 |
| 甲種 | 45問 | 法令15／物化10／**性質消火20（全類）** | 五肢択一 | 2時間30分 |
| 丙種 | 25問 | 法令10／燃焼・消火5／性質消火10 ※内訳は**要公式確認** | **四肢択一** | 1時間15分 |

設計に効く差分:
1. **丙種は四肢択一**（乙・甲は五肢）→ 選択肢数を可変に。
2. **甲種の性質消火は全6類20問** → 乙4（第4類のみ）とは別データ。
3. **丙種は第4類の一部に限定** → 乙4問題の一部が流用候補だが四肢化が必要。

### 着手前に一次情報で確定させる事項
- 丙種の科目別問題数（法令10／燃焼消火5／性質10 は一般説。公式PDFで確定）
- 甲種の受験資格（化学系単位／実務2年／乙種複数区分 等）
- 最新の受験手数料・試験時間

一次情報の起点: 消防試験研究センター https://www.shoubo-shiken.or.jp/kikenbutsu/

## 4. 設計の5本柱

### (1) 情報設計 — 試験軸を一段上に置く
- 入口で試験を選択 → 各試験の学習導線（過去問・一問一答・ガイド）へ。
- **既存の乙4 URL（`/q/` `/articles/` `/terms/` 等）は完全保持**。新試験は `/kou/` `/heishu/` 配下か `?exam=` で追加し、既存に影響を出さない。

### (2) データモデル — 1系統に `exam` 軸を追加（汎用）
- 問題CSVに `exam` 列を追加。既存データは全て `otsu4`。
- 選択肢は `choice_1〜5` を維持。**丙種は choice_5 空＝四肢**と判定。
- 試験の定義（表示名・科目構成・問題数・選択肢数・形式・時間）は **site-config 側の設定**として持ち、コードに埋め込まない（隣接資格追加に備える）。

### (3) 重複回避 — 共通科目は共有、独自は差分だけ（GSC対策 / CLAUDE.md ルール1）
- **法令・物化は共通系統を参照**（問題を複製しない）。甲種の深い論点だけ `exam:kou` で追加。
- 独自化するのは **性質消火（甲=全類／丙=限定）＋制度情報＋試験固有のSEO記事**のみ。

### (4) コンテンツ — 試験固有の切り口で新規執筆
- 「乙4→甲種のステップアップ」「丙種と乙4どちらを取るか」など固有テーマ。
- 乙4記事の使い回し・定型文は禁止（CLAUDE.md ルール1）。

### (5) 段階展開 — 既存非破壊を最優先
各フェーズ末で `python3 tools/build_all.py` が exit 0、乙4のURL・出力に差分が出ないことを担保してから次へ。

## 5. ロードマップ

- **フェーズ0（設計）**: `exam`軸＋四肢対応を既存ビルドを壊さず入れるための、データ・SPA・検証スクリプトの改修箇所を洗い出し、設計書に落とす。
- **フェーズ1（丙種）**: 四肢対応を実装 → 丙種の制度ページ＋性質消火問題を少数から。法令・物化は共通参照。
- **フェーズ2（甲種）**: 性質消火20問（全類）データ＋受験資格・ステップ記事を追加。
- **フェーズ3（横断）**: 「乙4の次に何を取るか」ハブ、免除・コンプリート動線。
- **将来**: 乙他類 → 消防設備士等の隣接資格（汎用モデルを活用）。

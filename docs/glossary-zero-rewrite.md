# 用語詳細 ゼロ書き直しフロー

422語の用語詳細を **部分修正ではなく全面差し替え** する運用手順です。正本の完成例は **アセトアルデヒド**（`data/glossary_terms.csv`）。

関連: [glossary-term-template.md](./glossary-term-template.md) · [editorial-quality.md](./editorial-quality.md)

---

## 正確に書くための5ステップ（必須）

**執筆前に一次データを見る。** 記憶や旧 CSV を参照しない。

```bash
# 1. 一次ソース・ブリーフ（演習・一問一答・過去問）
python3 tools/glossary_rewrite_brief.py --term ジエチルエーテル

# 2. ブリーフに載った事実だけで CSV 行をゼロ執筆
#    → apply_glossary_rewrite.py のバッチデータに反映

# 3. ソース整合 + HTML 品質ゲート
python3 tools/glossary_rewrite_validate.py --term ジエチルエーテル

# 4. ビルド
python3 tools/build_glossary_pages.py

# 5. 再検証 + HTML目視（5分）
python3 tools/glossary_rewrite_validate.py --term ジエチルエーテル
```

### 執筆ルール（精度）

| ルール | 理由 |
|--------|------|
| 分類・代表例は **演習解説の文言** に合わせる | PF-xxx の正答と矛盾しない |
| `exam_points` に **PF-xxx または TF-PF-xxx** を1件以上 | トレーサビリティ |
| 例題は **一問一答候補** から選ぶ | 試験形式のブレを防ぐ |
| `related_terms` は **rewrite済み or 同バッチ** のみ | リンク先の品質崩れ防止 |
| 法令表記は **政令別表第1** に統一 | 「別表第三」は演習DB表記 |

## 進め方（バッチ単位）

1. **クラスタを決める**（3〜10語）。本文にリンクする関連語は同バッチか先に完了させる。
2. **素材を集める** — `data/past_questions.csv`、演習 CSV の `tags:term:〇〇`。
3. **CSV行をゼロ執筆** — 旧文は参照せず、下記テンプレで全列を書く。
4. **機械検証** — `validate_csv.py` → `verify_glossary_rewrite.py --term 〇〇` → `build_glossary_pages.py`。
5. **HTML目視**（1語5分）— 下記チェックリスト。
6. **デプロイ** — バッチごとに `main` push（GitHub Actions）。

**目安:** 3〜5語/日（品質優先）。10語/週を基本ペースとする。

## 列の役割（1文を複数列に書かない）

| 列 | 役割 |
|----|------|
| `short_def` | 1文。「まず押さえる要点」専用 |
| `index_summary` | 一覧用120字前後（`short_def` と別角度） |
| `definition` | 2〜3文（法令・区分の骨格） |
| `article_lead` | 72字以上・リード専用（試験での出方） |
| `term_detail_body` | 本文（`###` 見出し3〜4、必要なら比較表） |
| `exam_points` | 箇条書き3項目（`;` 区切り） |
| `explanation` | 選択肢の論点（×肢の型） |
| `common_mistakes` | 誤解3項目 |
| `memory_tip` | `■` ラベル2項目 |
| `example_*` | 正誤1問または実過去問形式 |
| `faq_1〜4` | 定義 / 出題 / 誤解 / 復習（各100字以上） |
| `legal_basis` | 別表・条番号まで具体化 |
| `related_terms` | 2〜3語（本文・比較表に出す語のみ） |

### `term_detail_body` の型（品名・火災系）

```markdown
### 法令上の位置づけ
（消防法＋政令別表第1）

### 指定数量と性質（または試験の論点）
（数値・過去問番号）

### 近い品名・用語との違い
| 用語 | 区分 | 押さえる差 |

### 消火・取扱（該当する場合）
```

パイプ表を本文に入れると、ビルダーは自動比較表を出しません（重複防止）。

## 公開前チェックリスト

### 機械（必須）

```bash
python3 tools/validate_csv.py
python3 tools/verify_glossary_rewrite.py --term 用語名
python3 tools/build_glossary_pages.py
python3 tools/verify_glossary_rewrite.py --term 用語名   # 再実行
```

### HTML目視（必須）

- [ ] 同一段落が2セクション以上にない
- [ ] 法令欄に「…根拠法令です」がない
- [ ] 「別表第1**上的**」がない（「政令別表第1**上の**」は可）
- [ ] 比較表・関連語に **別物質名の連結**（「アニリンは、エチレングリコールは…」）がない
- [ ] 過去問リンクは用語名が本文に出る問題のみ
- [ ] 例題が「…正しいか、誤りか。」または試験らしい形式
- [ ] FAQ4問が定義/試験/誤解/復習で被っていない
- [ ] リンク先関連語の `short_def` も1文で成立している

## ツール一覧

|----------|------|

## アンチパターン（再発防止）

- 422語を一括執筆・一括デプロイ
- 監査スコア0だけで合格判断
- 関連語ページが古いまま `related_terms` だけ更新
- `article_lead` に「このページは、危険物取扱者試験…」定型を残す
- `memory_tip` に「過去問を1問…」の自動追記を手書きで重複

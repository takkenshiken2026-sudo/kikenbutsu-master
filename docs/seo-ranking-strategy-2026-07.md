# SEO 平均掲載順位 改善戦略（2026-07 GSC分析）

対象: kikenbutsu-master.jp / 目標: 平均掲載順位の引き上げ（現状 約10位 → Top5射程）
データ: Google Search Console「過去3か月」（2026-05-20〜2026-07-18）

## 1. 現状サマリー

- 直近60日で **平均掲載順位 19.3位 → 9.9位**、クリック 119→191、表示 4,837→9,094。上昇軌道。
- インデックス対象記事のタイトル・メタは固有で最適化済み。オンページSEOはプロ水準。
- ドラッグ構造（表示回数加重）: /articles 70%（加重10.2）/ /q 20%（13.0）/ /terms 7%（9.3）/ homepage 3%（26.4）。

## 2. データで否定された仮説（重要・労力を割かない）

- **低順位ページの間引き（noindex）**: 30位以下を全除外しても加重平均 11.1→9.4 どまり。ドラッグは裾ではなく本体全体に均一分布。
- **タイトル/メタの重複解消**: 検索に出るインデックス記事に重複は無い（重複タイトルは全て後述の引退ページで、検索結果に出ない）。
- **過去問ハブ・難易度ページのオンページ再最適化**: title/meta は既に良好。低順位の主因は競合の強さとドメイン評価。

結論: **平均が約10で頭打ちなのは若いサイトの権威性・競合の壁であり、機械的施策では動かない。**

## 3. サイト構造の実態（誤解しやすい点）

このサイトは既に **ハブ統合＋引退リダイレクト** で整理されている。

- 重複しがちな細粒度ページは **`noindex` + meta refresh + canonical** で統合先ハブへリダイレクト済み。
  - 例: `cbt-computer-exam → exam-format-overview` / `exemption-system・concurrent-exam-rules → exam-eligibility` / `reschedule-and-absence → exam-schedule` / `pass-only-past-questions-myth → past-question-strategy`
- GSCで引退ページ（cbt 7.0位・exemption 9.4位・reschedule 6.4位など）が今も上位表示されるのは**統合の移行期**。やがて統合先ハブへ評価が集約される。

**注意**: 引退ページへ内部リンクを張るのは無意味（自己ループ・リダイレクト先送り）。内部リンクは必ず統合先ハブへ張ること。

## 4. 戦略（勝てる所に集中）

### レバー1: 統合先ハブが「吸収した検索意図」を確実にカバーする（最優先・実効的）
統合で消えた細粒度ページの意図を、ハブ本文が十分にカバーしていないと、引退ページが消えた瞬間に順位を失う。**ハブのカバレッジ監査＋不足の補完**が最も確実な打ち手。

| 統合先ハブ | 吸収した意図 | カバレッジ | 対応 |
|---|---|---|---|
| exam-schedule | 欠席・日程変更・キャンセル（reschedule 6.4位/299表示） | **欠席の記述0件だった** | 「申し込み後に受けられなくなったら」節を追加（実施済み・公式facts） |
| exam-format-overview | CBTの有無（cbt 7.0位/424表示） | FAQで回答済み | 必要ならCBT節を拡充 |
| exam-eligibility | 免除（exemption 565表示） | 免除16件・良好 | 現状維持でよい |
| exam-eligibility | 併願・同時受験（concurrent 532表示/8.7位） | **併願の記述0件だった** | 「複数の乙種を一度にまとめて受けられるか」節を追加（実施済み・公式facts） |
| past-question-strategy | 過去問だけ・丸暗記で受かるか（myth 413表示/7.1位） | **myth観点の記述0件だった** | 「過去問だけ・丸暗記で受かるか」節を追加（実施済み・公式facts） |
| exam-format-overview | CBTの有無（cbt 7.0位/424表示） | FAQで回答済み・本文2件 | 優先度低（必要なら本文拡充） |

### レバー2: 競合の広域ヘッドワードは長期戦
`過去問`(606表示/14〜35位) `難易度`(84表示/92位)は競合が強い。一次情報の網羅性・独自データ・被リンク獲得でしか動かない。**短期KPIから外す。**

### レバー3: 権威性（E-E-A-T＋外部リンク）を積む（コード外・根本）
監修者の実名/資格の明示、更新日の実運用、外部からの被リンク導線。本体10→6の主因はここ。

## 5. KPIの組み替え

- ❌「全クエリ平均5.0」→ ⭕「勝てる主力20クエリの平均を10→5」＋「/articles加重順位 10.2→7」
- 達成すればGSC全体平均も自然に7位台へ。5位射程はその先、権威性が乗ってから。

危険物取扱者試験（乙4）の学習メモの取り方

乙4の学習メモは、テキスト写しより「演習直後の1行記録」と解き直し日の固定が定着の中心になります。ノートを分冊しすぎると、法令・物性・火災予防をまたいだ混同の再発に気づきにくくなります。筆記は四肢択一・50問・三領域、乙種の受験手数料は5,300円（要項で再確認）が目安です。本記事では一般財団法人 消防試験研究センター要項を正本に、1冊統合の構成、演習後テンプレ、週日曜10分の見返し、直前1か月の絞り込みを表にまとめます。根拠の数値・条文は政令・テキスト・要項で必ず上書き確認してください。

この記事の要点

本記事を読むと、乙4の学習メモを1冊に統合し、誤答理由と解き直し日を残して復習効率を上げる手順が分かります。

  • 復習サイクルの作り方
  • 間違いの分類
  • 苦手分野の優先順位
  • 偶然正解の見直し
  • 直前までの維持

11冊統合メモの基本構成

乙4は三領域が絡むため、メモは1冊にまとめます。

| セクション | 記録内容 | 週次の見方 |
| --- | --- | --- |
| 学習記録 | 日付・領域・正答数/出題数 | 最弱領域の特定 |
| 間違い | 問題ID・理由タグ・根拠1行 | 解き直し優先 |
| 用語 | 混同ペア・定義の差1行 | 演習5問へ接続 |
| 付箋索引 | テキスト頁→ノート行 | 直前の読み返し |

3冊に分けると解き直し時に領域をまたぎ、再発語の件数が見えなくなります。理由タグの型は「誤答理由の分類」記事と揃えてください。

2テキスト読書時の記録ルール

テキストは全文写しを避け、付箋＋1行要約に留めます。

| ルール | 内容 | 上限 |
| --- | --- | --- |
| 付箋 | 迷った段落に1枚 | 1章5枚まで |
| ノート | 付箋ごとに1行要約 | 条文番号＋論点 |
| 数字 | 一覧表へ転記 | 根拠行を必須 |
| 演習 | 該当章の5問 | 写し終わり後 |

「なぜ付箋を付けたか」が1行で言えない段落は、先に演習で出た誤答から開き直す方が効率的です。数字表の設計は「数字・期限の整理」記事と表を共有できます。

3演習後の1行記録テンプレ

演習直後は、次の5項目を毎回同じ順で書きます。

| 項目 | 例 | 用途 |
| --- | --- | --- |
| 問題 | 法令演習 #42 | 解き直しの特定 |
| 結果 | 誤答（2択まで） | タグ判定 |
| 理由 | 混同・条文未読など | 対策の種類 |
| 根拠 | 政令○条・用語slug | 正本への戻り |
| 再挑戦 | 3日後 / 7日後 | カレンダー登録 |

24時間以内の記録が、解き直しの再現率を上げます。2択まで絞れた誤答は「なんとなく正解」の見直し記事の別リストにも転記してください。

4週日曜10分の見返し

日曜は「読む」より「解き直しへ送る」時間にします。

| 曜日 | 作業 | 目安時間 |
| --- | --- | --- |
| 日曜 | 付箋ページ＋間違い上位10行 | 10分 |
| 月〜土 | 演習後1行のみ | 各回3分 |
| 2週ごと | 同じ10問の正答数を先頭に追記 | 5分 |
| 月1回 | 理由タグ別件数を集計 | 10分 |

3日後・7日後の再挑戦日をカレンダーに書き、新規演習より解き直しを先に確保します。全体の周期は「過去問の解き直しサイクル」記事で固定すると続きやすいです。

5直前1か月のメモ絞り込み

直前はメモの新規ページを増やしません。

1. 付箋が付いたテキスト頁だけ読み返す
2. 再発3回以上の行だけ解き直し（各5問）
3. 3連続正解＋根拠1行が言える行は卒業
4. 新規テキスト写し・問題集の追加は禁止
5. 数字表の上段10行だけ声出し（15分/日）

範囲拡大より、メモにある論点の再確認が得点に効きます。間違いノート運用は「間違いノート」、試験日・会場は「試験日程の確認手順」で要項と照合してください。

6よくある質問

学習メモは紙とデジタル、どちらが向いていますか？
どちらでも構いません。重要なのは1冊統合と演習直後の1行記録です。デジタルは検索が速く、紙はテキストと付箋の往復が速い場合があります。2週間、理由タグ＋再挑戦日の運用を試してから形式を決めてください。根拠の条文・数量は政令・要項・テキストが正本です。
メモに書く根拠は参考書の解説で足りますか？
解説は補助に留め、条文・政令表・要項の出題範囲で1行要約を検証してください。教材の年度が要項とずれていると、根拠行も古くなるため、目次と範囲表を突き合わせてからメモに採用します。改定後は古い根拠行を削除し、上書き確認を月1回入れてください。
メモの取り方と間違いノート記事の違いは？
本記事は1冊統合と1行記録・付箋索引の設計、「間違いノート」は誤答リストの優先順位と解き直し量が中心です。先に本記事のテンプレで記録を始め、件数が20行を超えたら間違いノート記事の週次運用に移してください。誤答の型は「誤答理由の分類」と表を共有すると迷いが減ります。

危険物取扱者試験（乙4）の概要【50問·三領域·5,300円】

危険物取扱者試験（乙種第4類・乙4）は、第4類危険物の取扱いに必要な知識を問う国家資格試験です。筆記は四肢択一・50問・法令·物性·火災予防の三領域、受験手数料は5,300円（要項で再確認）が目安です。初めて調べる方は、要項PDFで5項目を1枚にメモし、演習10問で現在地を記録するDay0から始めます。

1乙4の試験形式（50問·三領域）

乙4の筆記は、要項どおり四肢択一・50問です。出題は法令·物性·火災予防の三領域に分かれ、おおむね各17問前後・合計50問が目安です。

項目一般的な案内（要項で再確認）
問題数50問
形式四肢択一
領域法令·物性·火災予防
時間60分前後
合格35/50前後

統一試験とCBTの違い、持ち物の違いは試験形式記事で詳述します。例えば6月14日に上表を要項で上書き確認し、6月21日に50問に近い演習セットで時間を計測すると全体像が掴めます。

2要項で最初にメモする5項目（Day0）

初日は教材を買い漁らず、要項PDFから次の5項目だけを1枚に写します。

1. 問題数·形式（50問·四肢択一）
2. 出題領域（三領域）
3. 合格基準（35/50等·足切り）
4. 受験手数料（5,300円等）
5. 自分の支部の次回試験日·申込締切

5項目が揃うと、学習計画の週次時間を現実的に見積もれます。たとえば10月18日試験が一覧で分かれば、6月14日のDay0メモに「試験日·締切·35/50」を書き、学習計画記事で週8時間の配分に進みます。

3演習10問で現在地を記録する

要項メモのあと、演習10問で「いまの実力」を数字にします。領域別にばらけた10問でも構いません。

記録書き方
日付6/15等
正答6/10等
弱点物性·計算等1行
次15問演習日

正答率が低くても問題ありません。低い領域が分かればよいです。例えば6/15に演習10問で4/10·弱点物性なら、6/22から物性15問を週1回入れる、と次の行動が決まります。演習はサイトの過去問·一問一答から無料で始められます。

4受験資格·申込·日程の入口

試験概要を把握したら、手続き系は専門記事に委ねます。

受験資格 … 18歳以上·3ルート（要項表）
申込 … 支部ごとの期間·5,300円
日程 … 試験日程一覧の自分の行
形式 … 統一試験/CBT

「乙4と丙種·甲種は別試験」という点だけここで押さえ、詳細は受験資格記事·申込の流れ記事·試験日程記事へ進んでください。例えば6月16日に資格ルートを1行確定し、6月17日に日程一覧で次回試験日をカレンダー登録する順がおすすめです。

5概要を知ったあとの次の一歩

Day0が終わったら、次は学習の型を1つ決めます。

初学者 … 学習計画記事で週8時間·三領域ローテ
演習中心 … 過去問の使い方記事で50問通しの入れ方
範囲不安 … 出題範囲表の読み方記事で要項表の転記
合格ライン … 合格点記事で35/50と足切り

例えば6月15日演習10問完了後、6月16日に学習計画記事で週次表を書き、6月21日に初めて領域別15問を入れる、という3ステップで十分です。一度に全記事を読む必要はありません。

6よくある質問

危険物乙4とはどんな試験ですか？
第4類危険物の取扱いに必要な知識を問う国家資格試験です。筆記は四肢択一·50問·法令·物性·火災予防の三領域が基本です。例えば初日は要項PDFで50問·35/50目安·5,300円をメモし、翌日に演習10問で正答数を記録する、というDay0から始めてください。
乙4と丙種·甲種の違いは？
問題数·受験資格·取扱範囲が異なる別試験です。「危険物」でまとめた情報を、そのまま乙4の申込に使わないでください。例えば丙種免状を持っていても、乙4の受験資格は要項の3ルート表で別途判定が必要です。受験資格記事で該当ルートを確認してください。
最初に何から始めればよいですか？
要項PDFの5項目メモと演習10問の記録から始めます。教材を複数買う前に、試験日·合格ライン·三領域を1枚にまとめ、過去問·一問一答で10問解いて正答数を書き留めてください。例えば6/14要項·6/15演習10問完了なら、6/16から学習計画記事に進む流れが安定します。

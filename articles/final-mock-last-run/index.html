危険物取扱者試験（乙4）直前の最終演習

乙4の直前の最終演習は、新しい問題集ではなく要項時間の50問通し1回が目安です。通しを増やしすぎると睡眠と解き直しが削れ、直前は「記録して終える」ことが目的になります。筆記は四肢択一・50問・法令・物性・火災予防、試験時間・合格基準は一般財団法人 消防試験研究センター要項が正本です。本記事では最終通しの実施タイミング、記録する5項目、直後の解き直し、2回目以降をやめる線引きを表にまとめます。統一試験とCBTで手続きが異なる場合は受験票どおりに準備してください。

この記事の要点

本記事を読むと、直前にいつ最後の50問通しを受け、何を記録してその後何をするかが分かります。

  • 直前1〜2週間の絞り込み
  • 最終確認リスト
  • 当日のタイムライン
  • 持ち物と時間配分
  • メンタル・トラブル対応

1最終通しを受けるタイミング

50問通しは、直前週の前半に1回だけが目安です。

| 日 | 実施 | 理由 |
| --- | --- | --- |
| D-7〜D-5 | 最終通し1回 | 時間配分の確認 |
| D-4 | 解き直しのみ | 睡眠確保 |
| D-3〜前日 | 通し禁止 | 体調・持ち物優先 |
| 当日 | 本番 | 記録は見ない |

週全体の設計は「直前1週間の対策」記事のD-7行と揃えてください。試験時間の数値は要項の試験方法の表が正本です。

2通し後に残す5つの記録

終了直後に、次を必ず書きます。

| # | 記録 | 用途 |
| --- | --- | --- |
| 1 | 所要時間 | 配分の再現 |
| 2 | 領域別正答数 | 最弱領域の特定 |
| 3 | 未解答数 | マーク運用 |
| 4 | マークミス数 | 当日の注意 |
| 5 | 2分超えた問題番号 | 後回し練習 |

正答率の％より、未解答とマークミスを先に減らすと当日の得点に効くことが多いです。時間計測の型は「時間を計った演習」で事前に練習してください。

3通し直後24時間の作業

通しの翌日までに、次を終えます。

| 順 | 作業 | 時間 |
| --- | --- | --- |
| 1 | 誤答に理由タグ＋根拠1行 | 30分 |
| 2 | 未解答・マークミスを別リスト化 | 10分 |
| 3 | 最弱領域10問だけ解き直し | 20分 |
| 4 | 解き直し日をカレンダー登録 | 5分 |

新しい年度・問題集は開かず、「過去問の解き直しサイクル」の間隔に乗せます。絞り込みは「直前の範囲の絞り方」の20行リストへ転記してください。

42回目以降の通しをやめる判断

次のいずれかなら、通しの追加は不要です。

  • D-5より後の日付
  • 1週間以内に通しを既に2回実施した
  • 睡眠が7時間未満が3日続いている
  • 誤答解き直しが20行を超え未消化
  • 持ち物・会場が未確認

代替は、領域別15問と数字表10行の声出しです。通しの記録表は当日持参せず、前日までに解き直し日だけカレンダーへ移します。当日の配分は「当日の時間配分」記事と要項で確認してください。

5統一試験・CBT共通の心構え

形式が違っても、直前の目的は同じです。

| 目的 | やること | やらないこと |
| --- | --- | --- |
| 時間 | 要項時間で1回計測 | 無時間の大量演習 |
| 記録 | 5項目を紙に残す | 正答率だけ見る |
| 体調 | 通し後は睡眠優先 | 徹夜の解き直し |
| 手続き | 受験票どおり準備 | まとめサイトの手順 |

CBTの操作確認は要項・受験票の案内が正本です。前日の持ち物・会場は「前日チェックリスト」で最終確認してください。

6よくある質問

直前1週間で50問通しは何回受ければよいですか？
要項時間での通しは1回が目安です。D-7に1回実施し、それ以降は解き直しと持ち物・会場確認に寄せてください。2回目は睡眠と解き直しが削れるため、領域別ミニ20問で代替する方が安全です。試験時間・問題数は消防試験研究センター要項が正本です。
通しの正答率が低いときはどうしますか？
新しい問題集を増やさず、記録表の最弱領域10問の解き直しを先に行います。未解答とマークミスを別リストにし、当日は「取れる問題優先」の配分を「当日の時間配分」で確認してください。2週間後に同じ通しを再実施するのは、試験日が十分に先の場合のみに留めます。
最終演習記事と時間を計った演習記事の違いは？
「時間を計った演習」は学習期の通し・配分の練習方法が中心、本記事は直前1週間での最後の1回と記録・停止ラインが中心です。通常期は時間を計った演習で型を作り、直前週は本記事の1回ルールに切り替えてください。合格基準も要項の「合格の基準」章で上書き確認してください。

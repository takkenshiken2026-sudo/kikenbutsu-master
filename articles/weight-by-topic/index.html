危険物取扱者試験（乙4）の分野別出題比重と学習時間の配分

乙4の分野別の重要度は、ネットの配点議論より自分の演習データで決める方が得点に直結します。分野構成の正本は消防試験研究センターの当年度要項と公式テキストの出題範囲表です。筆記は四肢択一・50問・法令・物性・火災予防の三領域、受験手数料は5,300円（要項で再確認）が目安です。本記事では三領域リストの作成、領域別正答率の記録、正答率40％未満の1領域への時間再配分、月2回の50問通し、直前の弱点集中を表にまとめます。均等配分のまま進めるより、通し演習後の最弱領域に時間を寄せてください。

この記事の要点

本記事を読むと、要項の三領域配分の確認方法と、自分の演習正答率から学習時間の優先順位を決められるようになります。

  • 出題範囲の確認先
  • 範囲の全体像と改定
  • 科目・配点
  • 制限時間と出題形式
  • 過去問との対応

1分野配分の正本

分野配分の正本は要項の出題範囲表と公式テキスト目次です。

| 資料 | 用途 | 注意点 |
| --- | --- | --- |
| 要項 | 三領域名・出題範囲の定義 | 甲種・丙種の表と混同しない |
| テキスト目次 | 章ボリュームの目安 | 改定版か奥付で確認 |
| 自分の演習記録 | 優先順位の主指標 | 領域別正答数を2週間ごと |
| 非公式配点表 | 参考のみ | 要項で上書き検証 |

三領域を1枚の紙に写し、学習計画表の裏面に貼ると進捗が見えやすくなります。科目・配分の詳細は「出題科目・三領域と配分」、計画の骨格は「学習計画の立て方」で確認できます。

2改定年度の領域比重

改定で領域比重が変わる年度は要項の出題範囲表で確認します。

| 確認 | 学習への反映 |
| --- | --- |
| 章の追加・削除 | 週次配分表を1行修正 |
| 領域名の変更 | 演習タグとノート表記を統一 |
| 問題数・足切り | 50問通しの記録票を更新 |
| 改定章 | 一時的にその領域へ週+5時間 |

配点議論だけで学習順を入れ替えず、改定章は「出題範囲の改定履歴」の手順で同領域演習15問から入ってください。改定の差分確認は要項PDF内検索で「改定」を確認する習慣が有効です。

3時間配分の目安（三領域）

均等配分せず、条文量・数値の多さ・自分の正答率で調整します。

| 領域 | 学習での特徴 | 時間配分の目安 |
| --- | --- | --- |
| 法令 | 長文肢・数量・設備 | 全体の35〜45％（目安） |
| 物性 | 計算・単位・数値暗記 | 全体の25〜35％ |
| 火災予防 | 手順・消火・貯蔵 | 全体の25〜35％ |
| 正答率40％未満 | 最優先 | 翌週+3時間（1領域） |
| 直前4週 | 弱点1領域 | 週の演習時間60％ |

  • 多くの受験者は法令で枠組みを作り
  • 物性で数値を足し
  • 火災予防で手順を固め

同時に三領域を薄く進めると散漫になるため、2週間で1領域を重点する方法が続きやすいです。

4通し演習データでの再配分

50問通し演習で領域別正答数と所要時間を記録します。

| 記録列 | 次週の反映 |
| --- | --- |
| 法令・物性・火災の正答数 | 40％未満の領域を重点 |
| 1問あたり時間 | 超過領域は同領域10問/日 |
| 論点タグ | 同タグ10問をまとめて解き直し |
| 月2回の通し | 足切りラインを下回る領域がないか確認 |

通しは月2回を目安にし、その間は領域別演習で弱点を潰してください。合格基準の数値は要項が正本であり、演習得点と要項の説明を照合する習慣が重要です。

5領域別演習での実行

優先順位は乙4マスターの領域別演習（法令・物性・火災予防）で実行します。

- 1. 要項範囲の1章読了→同領域演習10問（時間計測は2周目以降）
2. 三領域1周後
- 最弱1領域を2周目として集中
3. 月2回
- 50問通しで領域別正答数表を更新
4. 直前4週は新規範囲停止
- 誤答・数字・混同語中心
5. 足切りがある場合は要項表の最低正答数を記録票に転記

他類の配分表を流用しない

甲種・丙種・他乙類の問題数・領域は乙4と異なります。過去問の回し方は「過去問の使い方」、合格ラインは「合格点・合格基準の見方」を参照してください。

6よくある質問

ネットの配点表だけで優先順位を決めてよいですか？
非公式の配点表は参考程度に留め、自分の領域別正答数と50問通しの記録を主指標にしてください。三領域名と範囲は要項の出題範囲表と公式テキスト目次が正本です。改定年度は目次比較後に配分表を1行修正し、正答率40％未満の1領域に翌週の時間を寄せる運用が再現性が高いです。
公式情報はどこで確認しますか？
三領域構成・出題範囲・問題数は消防試験研究センターの当年度要項が正本です。https://www.shoubo-shiken.or.jp/kikenbutsu/ から要項PDFを保存し、公式テキスト目次で章ボリュームを確認してください。足切りの有無は要項「合格の基準」で申込前と直前に上書き確認し、学習用カレンダーと申込用カレンダーを分けると混同しにくくなります。
独学でも分野別の優先順位は決められますか？
はい。演習記録から領域別正答数を出せば独学で十分です。法令で枠組みを作り、最弱1領域に週5時間を集中し、月2回の50問通しで足切りを確認してください。領域別の回し方は「過去問の使い方」、週次計画は「学習計画の立て方」で具体化できます。

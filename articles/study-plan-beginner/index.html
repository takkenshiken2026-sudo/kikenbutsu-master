危険物取扱者試験（乙4）の初学者向け学習計画（8〜10か月）

乙4の初学者は、三領域を同時に追わず順番を決めることが第一歩です。筆記は四肢択一・50問・法令・物性・火災予防、受験手数料は5,300円（要項で再確認）が目安です。本記事では危険物未経験者向けに8〜10か月・週8時間想定で、法令→物性→火災予防の順、最初の3か月は2領域に時間の80％、2週間ごとの領域別正答率記録を表にまとめます。試験日は消防試験研究センターの試験日程一覧が正本です。3か月で一から合格を狙う短期計画は、初学者には負荷が高いことが多いです。

この記事の要点

本記事を読むと、初学者が無理なく続けられる学習ペースと三領域の回し方が分かります。

  • 全体像を分野に分ける
  • 学習期間の目安
  • 週間スケジュールの例
  • 復習日の入れ方
  • 直前期の調整

1初学者が先に固める2領域

初学者は三領域を同時に追わず、法令→物性の順がおすすめです。

| 時期 | 重点 |
| --- | --- |
| 月1〜2 | 法令のみ（他は用語10語/週） |
| 月3〜4 | 物性を追加（計算・単位） |
| 月5〜7 | 火災予防＋領域別演習厚め |
| 月8〜10 | 50問通し＋弱点領域の解き直し |

公式テキスト目次に印を付け、最初の3か月は2領域だけに時間の80％を使います。領域名は要項の出題範囲表と目次で統一し、試験日程一覧で確定した試験日から総期間を逆算してください。

28〜10か月・週8時間の目安

初学者の学習期間目安は8〜10か月・週8時間です。6か月計画は経験者向けです。

| 指標 | 目安 |
| --- | --- |
| 期間 | 8〜10か月（週8時間） |
| 判断 | 2週間ごとの領域別正答数の伸び |
| 焦りの対策 | 問題数より解き直しの質 |
| 非推奨 | 3か月で一から合格を狙うだけの計画 |

「遅い」と感じても、同じ10問を2週間後に解き直し正答が5問増えていれば前進です。申込締切と受験手数料5,300円は学習カレンダーと分離して管理してください。

3週8時間の初学者スケジュール例

週8時間の初学者向け型です。完璧に守れなくても週6時間以上なら前進です。

| 曜日 | 時間 | 内容 |
| --- | --- | --- |
| 月〜金 | 夜60分 | テキスト半章＋演習3問 |
| 土曜 | 2時間 | 演習10問＋解説読み |
| 日曜 | 2時間 | 解き直し＋用語10語 |

2週間だけ実測し、続けられるペースに週次時間を確定してください。過去問はテキスト該当章の後に10問から始め、50問通しの時間計測は2周目以降が目安です。

42週間ごとの正答率記録

初学者ほど日曜の解き直しと記録が理解の要です。

| 記録項目 | 書き方 |
| --- | --- |
| 日付 | 6/10 |
| 領域 | 物性 |
| 正答数 | 10問中6 |
| 原因 | 条文未確認 / 単位ミス / 時間切れ |
| 次週 | 同領域演習15問＋用語5語 |

2週間ごとに同じ10問を解き直し、伸びがなければその領域に+2時間を上乗せします。新しい章のインプットより、間違い10問を正解する方が次週の理解が深まります。

5直前期の教材ルール

直前2か月は初学者が最も焦りやすい時期です。

1. 新規教材・参考書の購入を止める
2. 弱点1領域＋解き直し90％
3. 睡眠7時間を削らない
4. 50問通しを月2回まで（要項どおり）
5. 8か月続いた日曜習慣を直前に壊さない

会場・持ち物・CBT/統一試験の違いは「試験日程の確認手順」と要項で2週間前までに完了させます。混同用語は直前に用語解説で10組だけ毎日見る運用も有効です。

6よくある質問

危険物の知識がなくても8か月で間に合いますか？
週8時間を8か月続け、月2領域重点と解き直しを守れば、多くの初学者が要項の合格基準に近づけます。個人差は大きいため、2週間ごとの領域別正答数で判断し、40％未満の領域は翌月の重点にしてください。試験日・出題範囲は消防試験研究センター要項が正本です。
初学者はどの領域から始めるべきですか？
法令（消防法・危険物令の骨格）から始め、物性・火災予防は順に追加する型が管理しやすいです。三領域を同時に浅く進めるより、2か月は法令に80％の時間を使ってください。用語解説で「第4類」「乙種第4類」などの混同を先に解消すると、後の演習で読み落としが減ります。
初学者向け計画と最初の30日プランの違いは？
「最初の30日プラン」は習慣づくりと記録の型、本記事は8〜10か月の月次配分が中心です。30日終了時の正答数記録をもとに、本記事の月次表を2か月目から当てはめてください。初受験者の手順全体は「初受験者向けガイド」も参照できます。

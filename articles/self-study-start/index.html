危険物取扱者試験（乙4）の独学の始め方【Day0·14日】

乙4の独学は、いきなり50問通しより「要項で前提を固定し、テキスト第1章から演習10問を回す」順が定着しやすいです。筆記は四肢択一·50問·法令·物性·火災予防、受験手数料は5,300円（要項で再確認）が目安です。本記事は6/14 Day0·要項30分·テキスト1冊·14日計測準備に特化します。12週配分は独学ロードマップ記事で先に確認してください。例えば6/11（木）·9/15（日）支部試験まで残り12週なら、6/14（日）Day0→6/17 50問計測→6/28 領域別記録、が定番です。

この記事の要点

本記事を読むと、独学を今日から始める手順と、たとえば「6/28（日）法令12/17·物性10/17を記録」までの14日型が再現でき、独学ロードマップ記事との使い分けも表で把握できます。

  • 独学前に公式情報を確認
  • 教材・参考書の選び方
  • 過去問で現在地を確認
  • 復習を計画に入れる
  • 直前期の絞り込み

例えば6/17（水）19:00-20:30に法令·物性·火災の50問通し計測を行い、6/18から弱点2領域を1行メモに書くのが定番です。

4演習と用語の1セット学習

1問ごとにテキスト章と用語解説を往復します。

1. 演習5問を60分枠で解く
2. 誤答語を用語解説で定義確認
3. 原因を1行メモ（混同·数値·主体）
4. 公式テキスト該当章を20分で読み返す
5. 7日後に同型5問を解き直す

たとえば6/15（月）法令演習で「指定数量500kg」を誤答したら、用語解説→テキスト物性章→6/22（月）に再演習5問、の往復が定番です。60分·1問72秒の本番感は後半に回してください。

6よくある質問

独学の始め方に予備校や通信講座は必須ですか？
必須ではありません。公式テキスト1冊·問題集1冊·乙4マスター演習·用語解説の4点で開始できます。例えば6/14（日）30分で要項確認後、6/15（月）から法令第1章+演習5問を60分枠で回すのが定番です。予備校なし独学記事でつまずきやすい点も併せて確認してください（要項で再確認）。
独学開始時、教材は何冊必要ですか？
開始時は2冊（テキスト1·問題集1）で十分です。例えば6/15（月）に目次で法令·物性·火災の章立てを確認し、6/16（火）までに1セットを決定してください。追加は2か月目以降·領域別正答数が12/17未満の弱点が固まってから検討します。危険物取扱者試験（乙4）の参考書の選び方の記事の比較表も参照してください。
独学の始め方と独学ロードマップの違いは？
始め方記事はDay0〜14の入口、ロードマップ記事は12週の配分です。例えば6/28（日）に本記事で法令12/17·物性10/17を記録したら、7/1からロードマップ記事のフェーズ3（弱点集中·週5h）へ進むのが定番です。14日で止まらず6/17計測日をカレンダー先頭に置いてください。

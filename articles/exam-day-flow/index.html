危険物取扱者試験（乙4）当日の流れ

乙4の当日は、暗記の追加より時間配分とマーク運用が得点を左右します。受付開始・試験時間・終了後の動きは支部・形式で異なるため、一般財団法人 消防試験研究センターの要項と受験票が正本です。筆記は四肢択一・50問・法令・物性・火災予防、会場到着は受付開始の60〜90分前を目安に逆算します。本記事では出発から終了までのタイムライン、50問の進め方、見直し5分、終了後の注意を表にまとめます。持ち物の最終確認は「当日の持ち物」記事と要項で行ってください。

本記事を読むと、当日の時間軸で何をすべきかと、本番中のマーク・見直しの型が分かります。

  • 最終確認リスト

  • 持ち物と時間配分

1出発〜受付までのタイムライン

当日朝は、次の順で動きます。

| 段階 | 目安 | 確認 |
| --- | --- | --- |
| 起床 | 出発逆算 | アラーム2つ |
| 朝食 | 軽め | 体調メモ1行 |
| 出発前 | — | 持ち物再点検 |
| 到着 | 受付60〜90分前 | 受験票・身分証 |
| 受付 | 案内どおり | 座席・注意事項 |

会場・ルートは前日に「前日チェックリスト」で固定しておき、当日は紙メモだけを見ます。遅延想定の余裕30分は出発時刻に含めてください。

2試験開始〜前半（問題の進め方）

50問は、取れる問題から固めます。

| フェーズ | 目安 | 運用 |
| --- | --- | --- |
| 序盤 | 得意領域 | 確実にマーク |
| 中盤 | 標準 | 2分で印→後回し |
| 計算・長文 | 後回し可 | 印を付けて進む |
| 見直し | 終了5分前 | マークミスのみ |

詳細な分配は「当日の時間配分」記事と要項の試験時間で事前に練習してください。直前の最終通し記録を当日は開かない運用も有効です。

3マーク・未解答・見直しのルール

本番中のミスを減らす型を固定します。

| 症状 | 対策 | 見直し |
| --- | --- | --- |
| マークミス | 1問ごと確認 | 終了5分前 |
| 未解答 | 印付け問題から | 空欄ゼロを目標 |
| 迷い2択 | 印を付けて進む | 残り時間で |
| 焦り | 呼吸1回 | 得意から再開 |

不安が強いときは「当日のメンタル対策」の短い手順に切り替え、論点の追加暗記は避けてください。

4終了後〜帰宅まで

終了直後は、次を守ります。

1. 解答の共有・SNS投稿は控える
2. 体調メモ（睡眠・不安・胃腸）を1行
3. 持ち物をリストどおり回収する
4. 合格発表日を要項・受験票でカレンダー登録
5. 復習は翌日以降、当日は休息優先

合否の公表方法は年度・支部で異なるため、「合格発表の見方」記事は発表日前に読んでおくとよいです。トラブルがあった場合は「当日のトラブル対応」を参照してください。

6よくある質問

当日朝に演習はした方がよいですか？
手応えのための短い演習5問までが上限です。50問通し・新しい章・長時間の暗記は避けてください。体調が悪い場合は演習なしで、持ち物とルート確認だけでも十分です。睡眠のルールは「直前の睡眠と体調」記事と揃えてください。
受付に遅れそうなときはどうしますか？
まず会場案内・受験票の遅刻扱いを確認し、可能なら別ルートで向かいます。連絡先が案内されていれば指示に従ってください。前日のルート確認は「前日チェックリスト」、当日のトラブルは「当日のトラブル対応」記事も参照できます。
当日の流れと当日の時間配分の違いは？
本記事は受付から終了までの動きとマーク運用が中心、「当日の時間配分」は50問の領域別・計算問題の分配が中心です。当日は本記事のタイムラインを見ながら動き、席についたら時間配分記事の表を開く運用がおすすめです。試験形式は要項の試験方法の表で必ず確認してください。

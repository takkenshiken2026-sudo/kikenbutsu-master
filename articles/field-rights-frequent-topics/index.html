危険物取扱者試験（乙4）の物性｜頻出論点の整理

乙4物性分野では、引火点と蒸気圧の大小比較、混合危険性、静電気対策、自然発火の条件が繰り返し問われます。数値の丸暗記より、演習の誤答から論点タグを付ける方が得点に直結しやすいです。筆記は四肢択一・50問・法令・物性・火災予防、乙種の受験手数料は5,300円（要項で再確認）が目安です。本記事では消防試験研究センター要項を正本に、頻出論点の優先順位、演習50問からの抽出手順、危険物の法令・火災予防との接点を表にまとめます。

この記事の要点

本記事を読むと、物性で優先して潰すべき頻出論点と、演習記録から弱点を絞り込む手順が分かります。

  • 過去問での確認方法
  • 他分野との関連

1頻出論点5種の早見表

物性分野で演習記録に載せる論点タグの例です。正式な数値・要件はテキスト・要項で確認してください。

| 論点タグ | 典型設問 | 確認の正本 |
| --- | --- | --- |
| 引火点・閃点 | 大小比較・分類 | テキスト表・用語解説 |
| 蒸気圧 | 揮発性・温度 | テキスト表 |
| 混合危険性 | 組合せの可否 | テキスト該当節 |
| 静電気 | 発生・対策 | テキスト・演習 |
| 自然発火 | 条件・品目 | テキスト該当節 |

5タグすべてを同時に暗記するより、演習の誤答が集中する2論点から順に潰す方が効率的です。

2演習50問から論点を抽出する手順

頻出論点の優先順位は、自分の演習記録から決めます。

| 手順 | 作業 | 出力 |
| --- | --- | --- |
| 1 | 物性分野50問を解く | 誤答リスト |
| 2 | 各誤答に論点タグ1つ | タグ別件数 |
| 3 | 件数上位2タグを抽出 | 今週の重点 |
| 4 | 該当章をテキストで読み直し | メモ1枚 |
| 5 | 同タグ10問を2週間後に再演習 | 再発率 |

タグ付けは5種類以内に抑えると、週次計画に載せやすくなります。誤答理由の分類は「誤答理由の分類」記事の型も参照してください。

3引火点・蒸気圧の頻出パターン

数値論点は計算記事とセットで学ぶのが安全です。ここでは頻出の「型」だけ整理します。

| パターン | 問われ方 | 対策 |
| --- | --- | --- |
| 大小比較 | 引火点・閃点の順序 | 代表値カード |
| 温度と蒸気圧 | 揮発性の判断 | 表の読み方 |
| 第4類の性質 | 品目別の特徴 | 用語解説往復 |
| 混合と揮発 | 組合せ＋揮発性 | 演習10問 |

換算の詳細は「物性の計算・換算」、場面形式は「物性の事例・場面問題」で深掘りしてください。数値はテキスト改定で変わるため、要項・最新版で必ず照合します。

4混合・静電・自然発火の読み分け

物性の手順系論点は、条件・品目・対策の3点セットで整理します。

| 論点 | 整理の軸 | 演習のコツ |
| --- | --- | --- |
| 混合 | 組合せ表・禁止 | 代表5組を演習 |
| 静電 | 発生条件・接地 | 場面5問 |
| 自然発火 | 品目・温度・表面積 | 条件整理 |
| 漏えい性 | 蒸気圧・換気 | 数値比較5問 |

長文肢では、品目名と条件（温度・量・容器）を下線引きしてから選択肢を見ます。再発が3回以上の論点は、テキスト該当節を音読してから演習に戻してください。

5危険物の法令・火災予防との接点

物性の頻出論点は、他領域の設問根拠にもなります。

| 物性論点 | 危険物の法令での接点 | 火災予防での接点 |
| --- | --- | --- |
| 引火点 | 第4類の取扱条件 | 火源管理 |
| 蒸気圧 | 貯蔵・換気基準 | 漏えい対策 |
| 混合 | 取扱禁止・注意 | 消火剤選択 |
| 静電 | 取扱手順 | 接地・消火 |

同一品名を想定して三領域を往復すると、場面問題の読みが速くなります。演習の論点別管理は「物性の演習の活かし方」、基礎に戻る場合は「物性の基礎」を参照してください。

6よくある質問

物性の頻出論点はテキスト目次順で覚えるべきですか？
目次順で1周するのは有効ですが、演習開始後は誤答タグの多い論点を優先してください。引火点と蒸気圧は多くの受験者が最初のボトルネックになるため、正答率が40％未満なら他章の新規を止め、該当章＋演習20問に集中する方が効率的です。出題範囲は要項が正本です。換算特訓は「物性の計算・換算」へ進んでください。
数値表は全部暗記が必要ですか？
全部暗記より、表の見方と代表品目の数値感を押さえる方が試験向きです。演習で出た品目だけテキスト表を開き、引火点・蒸気圧を1行メモする運用で十分なことが多いです。大小比較問題では定義と相対関係の理解が、個別数値の暗記より重要です。古い暗記カードはテキスト改定後に更新してください。
頻出論点を1週間でどこまで進めればよいですか？
新規論点は1〜2個に絞り、各論点で演習10問＋解き直し1回が現実的な週次量です。5論点を同時に開くと解きっぱなしになりやすいため、タグ別正答数を見て最弱1論点に週の時間60％を配分してください。2週間後に同論点10問で伸びを確認し、伸びがなければテキスト読み直しを優先します。

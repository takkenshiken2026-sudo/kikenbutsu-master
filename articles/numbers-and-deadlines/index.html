危険物取扱者試験（乙4）の数字・期限の整理

乙4は指定数量・倍数・手数料・申込締切など、数字と期限が得点と手続の両方に直結します。バラバラ暗記より、「誰が・いつまでに・何を」の一覧表に根拠（政令・要項・案内）を1行付けると更新時の修正が楽です。筆記は四肢択一・50問・三領域、乙種の受験手数料は5,300円（要項で再確認）が目安です。本記事では消防試験研究センター要項と消防庁の法令情報を正本に、一覧表の列設計、演習との接続、改定時の更新手順、直前の見直し頻度を表にまとめます。

この記事の要点

本記事を読むと、試験・法令・学習で使う数字と期限を一枚の表で管理し、演習と用語解説に接続する手順が分かります。

1一覧表の列設計（誰が・いつまで・何を）

数字・期限は、次の列で1枚にまとめます。

| 列 | 例 | 根拠の書き方 |
| --- | --- | --- |
| 項目 | 指定数量（ガソリン） | 政令○条・品名表 |
| 数値・期限 | 200L / 申込締切日 | 要項○頁・案内PDF |
| 誰が | 事業者・取扱者 | 条文の主体 |
| いつまで | 届出期限・試験日 | カレンダー連動 |
| 何を | 届出・設備・手数料 | 動詞で1行 |

SNSやまとめの数値は仮説として扱い、表の更新は必ず要項・政令・試験日程一覧で上書き確認してください。

2試験運用の数字（要項で固定）

受験手続きに関わる数字は、要項と試験日程一覧が正本です。

| 項目 | メモの置き場 | 更新タイミング |
| --- | --- | --- |
| 問題数・形式 | 50問・四肢択一 | 年度要項公開時 |
| 合格点 | 合格の基準章 | 同上 |
| 受験手数料 | 5,300円（要項で再確認） | 申込前 |
| 試験日・締切 | 支部別案内 | 申込直前 |

  • 合格点の読み方は「合格点・合格基準の見方」
  • 手数料と振込は「受験手数料の確認」
  • 日程は「試験日程の確認手順」で詳細を確認してください

3出題範囲の数字（政令・テキスト）

出題に関わる数量・期限は、政令表・テキスト表が正本です。

| 種類 | 学習の入り方 | 演習 |
| --- | --- | --- |
| 指定数量 | 品名表の読み方から | 算定10問 |
| 倍数 | 段階の一覧 | 同型5問 |
| 物性数値 | テキスト表を写す | 換算10問 |
| 期限・届出 | 誰が・何をを先に | 順序5問 |

暗記カードだけに依存せず、週1回は政令・品名表を開く練習を入れると本番で再現しやすくなります。算定演習は「指定数量・倍数の演習」、引っかけ対策は「数値問題の引っかけ」へ進められます。

4誤答3類型と表の修正

数字問題の誤答は、表のどの列を直すかが決まります。

| 類型 | 症状 | 表の修正 |
| --- | --- | --- |
| 単位 | L・kg・倍の取り違え | 換算行を追加 |
| 主体 | 届出者・報告者の混同 | 誰が列を太字 |
| 期限 | 日数・手続順の誤り | いつまで列を更新 |

再発3回の行は、用語解説で定義と根拠を確認してから同型演習5問を解き直してください。割合・濃度は「割合・濃度の問題」で別表に分けると混同を防げます。

5改定時の更新と直前の見直し

数字表は「作って終わり」ではなく、改定に合わせて更新します。

1. 要項・消防庁のお知らせを月1回確認
2. 変更行だけ表を上書き（古い行は削除）
3. 変更に関わる演習10問を解き直し
4. 直前1か月は毎日15分、表の上段10行のみ声出し
5. 試験2週間前は新規数字の追加を禁止

直前は範囲拡大より、表にある数字の再確認が得点に効きます。用語の優先度は「用語の重要度の見方」、公式の読み方は「公式情報の確認先と使い方」で確認してください。

6よくある質問

数字は暗記カードだけで足りますか？
カードは補助に有効ですが、政令・品名表を開く練習がないと、表の読み取り問題で再び誤ることがあります。週1回は根拠行を見ながら表を更新し、演習で出た数値だけカードに追加する運用がおすすめです。改定後は古いカードを削除し、要項・政令で上書き確認してください。
申込締切と学習の期限、同じ表で管理してよいですか？
同じ表でも構いませんが、列「誰が・いつまで・何を」で手続期限と出題数字を混在させないでください。手続は試験日程一覧とカレンダー通知を二重化し、出題数字は政令・テキスト根拠行を必ず付けます。申込前の確認手順は「試験日程の確認手順」記事も参照してください。
数字整理と計算ドリル記事の違いは？
本記事は一覧表の設計と期限・主体の整理、「指定数量・倍数の演習」は算定手順の反復演習が中心です。先に表で代表値と根拠を固定し、その後ドリル記事の手順で週次演習量を確保してください。公式の覚え方は「計算・公式の覚え方」で別枠の暗記と演習を設計できます。

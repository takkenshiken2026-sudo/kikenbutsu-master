危険物取扱者試験（乙4）は過去問だけで合格できるか

「過去問を回せば合格」は、範囲改定・足切り・言い換えがある乙4では危険な短絡です。過去問は本番形式の慣れに有効ですが、要項の出題範囲表と公式テキストが正本です。筆記は四肢択一・50問・法令・物性・火災予防、乙種の受験手数料は5,300円（要項で再確認）が目安です。本記事では過去問だけで足りない理由、範囲内判定、三領域維持、テキスト併用の比率、解き直し中心の直前運用を表にまとめます。年度をなぞるだけより、未演習の章を優先する方が得点に直結します。

この記事の要点

本記事を読むと、過去問の適切な位置づけと、テキスト・演習・用語を組み合わせる必要が分かります。

  • よくある誤解
  • 制度・出題の改定
  • 合格後の手続き
  • 不合格後の立て直し
  • 公式情報の優先

1過去問だけでは足りない理由

過去問単独では次の穴が残りやすいです。

| 穴 | 理由 | 補完 |
| --- | --- | --- |
| 範囲外 | 改定で除外 | 要項照合 |
| 足切り | 1領域の極端な低さ | 領域別演習 |
| 言い換え | 暗記だけ | 用語・解き直し |
| 数字 | 表の往復 | テキスト・用語 |

過去問は「形式慣れ」と「弱点の可視化」に強く、「範囲の網羅」は要項と教材が担います。使い方の全体は「過去問の使い方」で整理できます。

2範囲内かどうかの照合

各問題を解く前に照合します。

| 順 | 作業 | 確認先 |
| --- | --- | --- |
| 1 | 要項の出題範囲章 | PDF |
| 2 | テキスト目次と論点対応 | 該当節 |
| 3 | 該当なし→除外候補 | リスト |
| 4 | 解説の条文を原文確認 | 正誤 |

範囲外に時間を使うと、本番で効く論点の解き直しが止まります。手順の詳細は「出題範囲と過去問の対応」記事と共有できます。

3三領域バランス

過去問偏重でも三領域の維持が必要です。

| 領域 | 目安 | 記録 |
| --- | --- | --- |
| 法令 | 週の演習の一部 | 正答数 |
| 物性 | 数字表＋演習 | 混同タグ |
| 火災予防 | 場面問題 | 読みタグ |
| 通し | 月2回50問 | 足切り確認 |

1領域だけ過去問を厚くすると、他領域の基礎問で失点しやすくなります。配分は「出題科目・三領域と配分」で要項確認してください。

4テキスト・演習との比率

独学の目安比率です（週あたり）。

| 構成 | 比率 | 内容 |
| --- | --- | --- |
| インプット | 30％ | テキスト該当章 |
| 演習・過去問 | 50％ | 範囲内のみ |
| 解き直し | 20％ | 誤答・惜しい |
| 直前8週 | 解き直し60％ | 新規停止 |

過去問70％超が続く週は、解き直しを増やしてから次の年度に進んでください。教材選びは「参考書の選び方」で1冊に絞る判断ができます。

5過去問中心から卒業する条件

次の条件が揃えば、過去問比重を維持モードに移せます。

1. 要項範囲の未演習章がない（または優先リスト化済み）
2. 50問通しで領域別に極端な不足がない
3. 同じ20問の再テストで+2問以上の伸び
4. 範囲外リストが空に近い
5. 直前2週は解き直しと睡眠優先

条件未達のまま年度だけ増やすと、同じミスが本番まで残りやすいです。範囲全体は「出題範囲の全体像」で章立てを確認してください。

6よくある質問

過去問は何年分やればよいですか？
年数より、各問が現行範囲内かの照合が重要です。最新年度で現在地を測り、範囲内の旧年度で弱点補強する順が効率的です。改定章は最新版テキストと要項を正本にしてください。年度のなぞりだけでは足切りリスクは減りにくいです。
過去問だけ神話と過去問活用記事の違いは？
本記事は「過去問だけでは不足」の理由が中心、「過去問の使い方」は具体的な回し方・順番が中心です。神話を信じていたらまず本記事、運用設計は活用記事で週次表を固定してください。範囲照合は「出題範囲と過去問の対応」記事の手順と揃えてください。
実践演習だけではダメですか？
演習は量と弱点補強に有効ですが、範囲表と照合しないと範囲外・偏りが残ります。過去問形式の慣れは通し演習で、網羅は要項とテキストで補完する二刀流が安全です。解き直し比率を週40％以上に固定してください。

危険物乙4は過去問だけで合格できる？【35/50·三領域】

「過去問を回せば合格」は、範囲改定や領域別足切りがある乙4では危険な短絡です。過去問は本番形式の慣れと弱点の可視化に強い一方、出題範囲の正本は消防試験研究センター要項の出題範囲表と公式テキストです。筆記は四肢択一·50問·法令·物性·火災予防、合格目安は35/50前後（要項確認）です。

1過去問だけでは足りない理由

過去問単独では、次の穴が残りやすいです。

穴なぜ起きるか補完
範囲外法改正·改定要項照合
足切り1領域偏重領域別演習
言い換え暗記のみテキスト·用語
数字表の往復不足公式テキスト

過去問は「形式慣れ」と「弱点の可視化」に強く、「範囲の網羅」は要項と教材が担います。例えば6月の50問通しで物性12/17なら、過去問を増やす前に物性のテキスト章と15問演習を追加する判断が先です。

2範囲内かどうかの照合手順

各問題を解く前に、要項表と照合する習慣を付けます。

1. 要項の出題範囲章を開く
2. 問題の論点が表の行に存在するか確認する
3. 該当なしなら「除外候補」リストへ移す
4. 解説の根拠条文を公式テキストで開く

範囲外に週末を使うと、本番で効く論点の解き直しが止まります。たとえば「禁水物質」の過去問を解く前に、要項表の火災予防行とテキスト該当ページを1行メモしてから取り組むと、似た用語の引っかけに強くなります。手順の詳細は出題範囲表の読み方記事でも補足できます。

3三領域バランスを崩さない

過去問偏重でも、法令·物性·火災予防の最低限の配分は維持します。

領域週の目安記録
法令15問以上正答数
物性15問以上計算ミス
火災予防15問以上手順ミス
通し月2回50問足切り確認

1領域だけ過去問を厚くすると、他領域の基礎問で失点しやすくなります。例えばある週に法令過去問20問を解いたら、翌週に物性·火災各15問を必ず入れる、とカレンダーで交互にします。

4テキストと過去問の比率

初学者はテキストで論点を掴み、過去問で形式に慣れる順が安定します。

テキスト該当章を30分読む → 同領域過去問·演習15問 → 誤答3問を解説で確認 → 3日後に10問解き直し

「過去問だけ週20時間」より、「テキスト30分＋15問＋解き直し10問」の方が定着しやすいことが多いです。例えば6/8〜6/14は物性テキスト第4章を読み、6/15に物性15問・6/22に同じ15問の解き直し、というサイクルを1領域ずつ回します。テキストと過去問の優先順位は専用記事でも整理できます。

5過去問神話への対処まとめ

過去問は「合格の唯一の手段」ではなく、「要項範囲内の演習の一部」です。

やる … 月2回50問通し·領域別記録·解き直し40％以上·要項照合
やらない … 範囲外の古い問題集·1領域だけの偏り·解説を読まない解きっぱなし

例えば8月の50問通しで34/50でも、物性11/17なら足切りリスクがあるため、9月は過去問の量を増やす前に物性テキストと15問演習を週2回入れてください。過去問の回し方全体は過去問の使い方記事で具体化できます。

6よくある質問

過去問だけで危険物乙4に合格できますか？
範囲改定·足切り·言い換えがあるため、過去問単独はおすすめしません。要項の出題範囲表と公式テキストを正本にし、過去問は形式慣れと弱点発見に使ってください。例えば6月に要項表の未演習行から15問を選び、テキスト該当章を読んでから解く、という順が安全です。
過去問は何年分やればよいですか？
年数より「要項範囲内か」と「三領域バランス」が重要です。改定前の古い問題は除外候補リストへ移し、当年度要項表に存在する論点を優先してください。たとえば7月に50問通しを1回入れ、弱点領域の過去問を2週間サイクルで解き直す方が、年度をなぞるだけより効率的です。
テキストはいつ読めばよいですか？
過去問の前に、該当章を短時間で読む順がおすすめです。30分のテキスト読了→15問演習→誤答確認→3日後解き直し、のサイクルを1領域ずつ回してください。例えば物性が弱点なら、6/8にテキスト第4章、6/15に物性15問、6/22に解き直し、とカレンダーに書き込みます。

危険物乙4の合格点【35/50·足切り·要項の読み方】

危険物取扱者試験（乙種第4類・乙4）の合格基準は、消防試験研究センター要項の「合格の基準」章が正本です。公表されている合格率は参考値であり、自分の演習得点とは別物として扱います。一般的には50問中35問以上（70％前後）が目安とされますが、領域別の足切りがある場合は要項表で必ず確認してください。

1要項で確認する合格基準の読み方

合格ラインは感覚ではなく、要項の表から読み取ります。

項目確認先記録票への書き方
総合正答数合格の基準章35/50等
領域別同表の行法令·物性·火災
足切り脚注・別表最低正答数
年度差改正履歴確認日メモ

「去年の情報」で35/50を固定せず、申込前に当年度要項を開き直してください。例えば6月14日に30分で合格基準を写し、記録票の右上に「要項確認日：6/14」と書いておくと、後から版違いに気づけます。

235/50と三領域の足切り

合計35/50以上でも、1領域だけ極端に低いと不合格になる場合があります。

通し演習では、合計点だけでなく領域別正答数を必ず記録します。例えば「法令16/17・物性12/17・火災16/16・合計44/50」なら、物性の12/17が足切りラインに近いかを要項表と照合します。対策は物性に週2回・15問ずつ演習を追加し、2週間後に同じ15問を解き直す、という具体策まで落とし込みます。出題配分の目安は出題科目記事、時間の使い方は試験形式記事で補完できます。

3公表合格率との違い

合格率は「受験者全体の割合」であり、個人の演習32/50とは直接対応しません。

学習量を決めるときは、自分の50問通しの領域別正答数を優先します。合格率が高いからといって演習を減らす、低いからといって過剰に増やす、どちらも根拠が薄くなります。例えば6月21日の初回通しで32/50なら、合格率の数値ではなく「あと3問で35/50」という差分で次の2週間を設計します。合格率の読み方は合格率記事で、差分の潰し方は得点差分析記事で深掘りできます。

4演習記録票の作り方

記録票は1枚で足ります。次の欄を印刷または手書きで固定します。

日付 / 50問通しか領域別か / 法令正答 / 物性正答 / 火災正答 / 合計 / メモ

月2回の50問通しを入れ、間の週は弱点領域の15問演習を記録します。たとえば7月と8月に50問通しを入れ、その間の2週間は物性15問を各1回、というリズムが管理しやすいです。初回記録が32/50でも落ち込まず、足切り懸念の領域1つに絞って2週間で+3問を目指すのが現実的です。

5合格点まわりのよくある誤解

次の誤解に注意してください。

**32/50ならもう少しで合格** … 足切りがある場合は領域別も要確認。
**合格率が高いから余裕** … 個人の演習データが先。
**過去問正答率だけ見る** … 50問通しの領域別記録が必要。
**要項を読まず35/50と決め打ち** … 当年度要項で上書き。

例えば10月18日試験前の8月通しで34/50でも、物性が11/17なら足切りリスクがあるため、9月は物性重点の15問演習を週2回入れる判断が必要になることがあります。

6よくある質問

危険物乙4の合格点は何点ですか？
要項の「合格の基準」章が正本です。一般的には50問中35問以上（70％前後）が目安とされますが、年度・領域別足切りで変わるため、必ず当年度要項を開いてください。例えば要項写しの1枚目に「35/50・領域別○問以上」と書き、50問通しのたびにその表と照合する習慣が安全です。
三領域の足切りとは何ですか？
総合正答数に加え、法令・物性・火災予防それぞれに最低正答数が定められている場合があります。要項の表と脚注を読み、記録票に領域別欄を必ず用意してください。たとえば合計38/50でも物性が12/17で足切り未達なら不合格となる、といったケースを想定して演習を配分します。
公表合格率はどう見ればよいですか？
合格率は全体統計であり、個人の達成度の指標にはしません。学習の進捗は自分の50問通しと領域別正答数で判断してください。例えば6月21日32/50なら「あと3問」と差分を出し、弱点領域の15問演習を2週間続ける、という動きに変換します。合格率の読み方の詳細は合格率記事を参照してください。

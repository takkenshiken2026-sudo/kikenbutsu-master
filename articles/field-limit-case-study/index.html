1場面問題を分解する4点読み

長文肢は、選択肢を見る前に次の4点を下線引きします。

| 読み取り点 | 例 | メモ |
| --- | --- | --- |
| 品名 | ガソリン・アルコール等 | 適否・禁水の確認 |
| 数量 | 漏えい量・貯蔵量 | 措置の規模へ |
| 状況 | 屋内・屋外・火災の有無 | 手順の分岐 |
| 手順 | 措置→報告→消火 | 順序問題へ |

4点が揃ってから、消火方法の当てはめに進むと読み落としが減ります。数量の読み取りは「火災・消火・漏えいの計算・指定数量」を参照してください。

2典型シーン4種と演習の入り方

演習では次の典型シーンを偏りなく解きます。

| シーン | 焦点 | 演習目安 |
| --- | --- | --- |
| 漏えい発生 | 手順・報告 | 10問 |
| 火災発生 | 消火方法・避難 | 10問 |
| 貯蔵所 | 屋内・屋外の対策 | 10問 |
| 取扱・給油 | 禁止・注意 | 10問 |

各シーンで正答率60％未満なら、テキストの事例解説を読み直してから同シーン5問を再演習します。頻出論点の整理は「火災・消火・漏えいの頻出論点」、基礎は「火災・消火・漏えいの基礎」で確認してください。

3誤答3類型と修正ループ

場面問題の誤答は、次の3類型に分類して修正します。

| 類型 | 症状 | 修正 |
| --- | --- | --- |
| 読み落とし | 状況1つ見逃し | 4点読みの再訓練 |
| 手順誤用 | 似た手順の混同 | 順序図の音読 |
| 数量読み | 単位・規模ミス | 数量演習10問 |

「なんとなく正解」は再発率が高いため、正解でも4点メモを1行残す習慣をつけてください。見直しの型は「なんとなく正解の見直し」記事も参照できます。

4三領域往復で場面を固定する

同じ場面を三領域で往復すると、長文の理解が定着します。

| 領域 | 同シーンでの問い | 演習 |
| --- | --- | --- |
| 火災 | 消火・漏えい手順 | 5問 |
| 法令 | 届出・設備 | 3問 |
| 物性 | 引火点・揮発 | 3問 |

1シーンにつき11問を1セットとし、2週間後に火災5問だけ解き直します。法令・物性の分野別記事と組み合わせると、単一領域の暗記より記憶の保持率が上がりやすいです。

5演習記録と次のステップ

場面問題の記録は、シーン名と4点メモをセットにします。

| 列 | 例 | 用途 |
| --- | --- | --- |
| 日付 | 6/10 | 解き直し日 |
| シーン | 屋内漏えい | 弱点把握 |
| 4点メモ | 品名・量・屋内・手順 | 再発防止 |
| 結果 | 正解/誤答 | 再テスト |

50問通し前にシーン別正答数を確認し、最弱シーンに週5問を追加してください。演習の論点管理は「火災・消火・漏えいの演習の活かし方」、50問通しの組み込みは「過去問の使い方」で具体化できます。

6よくある質問

場面問題は消火方法を全部覚えないと解けませんか？
全部暗記は不要です。典型シーン4種と4点読みが定着すれば、多くの設問は条件整理→適否判断で解けます。未知の場面は、4点メモを書いてから選択肢を消去する順序を守ってください。手順が絡む場合は順序演習の量が不足していないか確認します。出題範囲は要項が正本です。
漏えいと火災が同時に起きた長文の読み方は？
まず状況列で「漏えいのみ」「火災発生」「両方」を分類してください。手順は漏えい措置が先か消火が先か、テキストの優先順位で確認します。4点読みの練習は短い場面問題5問から始め、1分で品名・数量・状況・手順だけを終える訓練が有効です。時間配分の全体像は「時間計測演習」で確認してください。
正解した場面問題も見直した方がよいですか？
はい。「なんとなく正解」は本番で再発しやすいため、正解でも4点メモを1行残し、1週間後に同型3問で確認することをおすすめします。適切な消火方法を1行説明できない正解は、誤答と同様に解き直し対象にしてください。見直しの習慣化は「なんとなく正解の見直し」記事の手順が参考になります。

危険物乙4 申込締切前チェックリスト【7日前·3日前】

危険物取扱者試験（乙種第4類・乙4）の申込締切直前は、書類不備・手数料ミス・統一試験とCBTの取り違えが重なりやすい時期です。締切は支部・回ごとに異なり、試験日程一覧が正本です。例えば8月31日17時締切なら、8月24日までに受験資格・写真・支部・方式を確定し、8月28日までに申込書提出と5,300円の納付を完了させる流れが安全です。

1締切7日前までに終えること

締切1週間前までに、申込の前提条件をすべて確定します。

項目確認内容正本
受験資格3ルートの該当要項
写真サイズ・枚数申込案内
支部·回試験日·方式日程一覧
手数料5,300円等要項

実務ルートなら勤務証明の職務欄が要項定義と一致するか、免状ルートなら写しの準備をこの時点で始めます。例えば8月31日17時締切なら、8月24日午後に上表を上からチェックし、未完了項目を8月25日までに人事・支部へ依頼するのが現実的です。

2締切3日前までに終えること

書類と納付は締切3日前までに完了させ、余裕を持たせます。

1. 申込書の記入漏れ・押印を確認する
2. 受験手数料5,300円（要項確認）を納付する
3. 振込控え・決済メールを保存する
4. 申込書の写しを撮影またはコピーする
5. 支部の提出方法（郵送·窓口·電子）を再確認する

統一試験とCBTで必要書類が異なる場合があるため、自分の回の案内PDFだけを開いて照合してください。たとえば8月28日午前中に提出完了・午後に控え整理、8月30日に写しと日程一覧の試験日を再照合する流れがおすすめです。

3締切前日·当日の最終確認

締切前日は「新規作業をしない」日です。確認と再提出の要否だけを見ます。

タイミング確認
前日振込控え·申込書写し·写真データ
当日朝支部の受付時間·持参物
提出後受付完了の連絡·控え番号

当日午後ギリギリの提出は、交通遅延やシステム障害で間に合わないリスクがあります。例えば8月31日締切なら、8月30日夕方に控えを開き、8月31日10時までに窓口・郵送・電子申込のいずれかで完了させる目標にします。

4よくある不備と予防

締切直前に多い不備は次のとおりです。

**写真サイズ不一致** … 7日前に案内どおりのデータを用意する。
**勤務証明の職務欄不足** … 実務ルートは2週間前から人事へ依頼。
**手数料の名義不一致** … 申込者名と振込名義を要項で確認。
**支部·CBTの取り違え** … 日程一覧の自分の行だけを転記。

例えば8月25日時点で写真が未準備なら、その日のうちにコンビニ証明写真か規格データを用意し、申込書記入は8月27日に集中させる優先順位を付けてください。

5申込の流れ記事との役割分担

申込全体のステップと、締切前チェックは記事を分けます。

申込の流れ記事 … 初めて申し込む人向けの全体手順·書類一覧
本記事 … 締切7日前·3日前の時系列チェック
受験資格記事 … 3ルート判定·勤務証明の中身
試験日程記事 … 支部·締切日·試験日の4点カレンダー

例えば初回申込なら申込の流れ記事で全体像を把握したあと、本記事のチェックリストを印刷し、締切日から逆算して7日前·3日前の日付を書き込んでください。

6よくある質問

申込締切はいつまでですか？
支部·回ごとに異なり、消防試験研究センターの試験日程一覧が正本です。自分の支部行の締切日時をカレンダーに登録し、7日前·3日前のリマインドを2つ付けてください。例えば8月31日17時締切なら、8月24日と8月28日をチェック日に設定する運用が安全です。
受験手数料5,300円はいつ納付しますか？
納付期限と方法は当年度要項·支部案内が正本です。締切3日前までに納付と控え保存を完了させるのが目安です。例えば8月28日に納付し、控えのスクリーンショットを申込書写しと同じフォルダに保存しておくと、前日の確認が速くなります。金額は年度で変わるため、申込直前に要項で再確認してください。
締切直前に資格が不安な場合は？
受験資格は要項の表で判定し、不明点は支部の問い合わせ先へ早めに連絡します。締切前日に初めて要項を開くのではなく、7日前までに受験資格記事どおり3ルートを確定してください。例えば実務ルートで勤務証明が間に合わない場合は、次回支部日程への延期を検討し、誤った申込は取り消し手続きを要項で確認します。

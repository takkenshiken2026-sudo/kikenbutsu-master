危険物取扱者試験（乙4）の申込締切前チェックリスト

申込締切直前のミスは、書類不備・手数料・方式の取り違えで不受理につながりやすいです。乙4は50問・三領域、受験手数料は5,300円（要項で再確認）が目安です。本記事では消防試験研究センター（https://www.shoubo-shiken.or.jp/kikenbutsu/）の要項と試験日程一覧を正本として、締切7日前・前日・当日の確認項目を表にまとめます。締切は支部・回ごとに異なるため、自分の支部行だけをカレンダーに登録してください。

1締切前の最優先（受験資格）

締切前の最優先は受験資格です。要項の受験資格表で自分の該当欄を確認します。

| 確認項目 | 見る場所 | 注意点 |
| --- | --- | --- |
| 学歴・実務 | 要項「受験資格」 | 欄ごとにチェック |
| 他免状 | 種類・取得日 | 写しの要否 |
| 勤務証明 | 様式番号 | 記入漏れ・押印 |
| 問い合わせ | 要項記載先 | 不明点は締切前に |

資格不明のまま申込すると後から無効となるおそれがあります。疑問点は申込前に試験実施機関へ確認し、回答をメモに残してください。

2日程・締切・支部の確認

申込締切日・試験日は試験日程一覧が正本です。他支部の例を流用しないでください。

| 登録するリマインド | 目的 |
| --- | --- |
| 締切7日前 | 書類・手数料の最終確認 |
| 締切前日 | 郵送なら投函完了 |
| 締切当日午前 | 電子・窓口提出の完了 |
| 試験日 | 学習計画の逆算 |

統一試験とCBTで申込欄が異なるため、自分の回の方式を印をつけてから申込書に転記してください。

3受験手数料と提出方法

受験手数料は乙種5,300円が目安です（年度・要項で再確認）。名義・金額ミスは不受理の典型です。

  • 振込・窓口・電子のいずれか（要項どおり）
  • 申込書と納付を同じ週に完了（片方だけは不可）
  • 控え・領収書を試験当日まで保管
  • 郵送は締切2〜3日前投函（必着・消印有効は要項確認）

手数料だけ先に済ませて申込書が未提出、という順序も失敗パターンです。書類と納付をセットで完了させてください。

4申込当日の最終リハーサル

提出直前に声に出して読み上げるチェックです。

1. 指定様式の申込書か（旧年度用紙でないか）
2. 氏名・生年月日が身分証と一致するか
3. 写真が要項のサイズ・背景どおりか
4. 受験支部・回・方式（統一試験・CBT）が正しいか
5. 手数料5,300円（要項確認）・名義
6. 封筒の表書き・提出先（郵送の場合）

完了後は受理通知・不受理の有無を1週間以内に確認し、その間も50問形式の演習は週1回継続すると学習が止まりにくくなります。

5印刷用チェックリスト

締切前に印刷して使える一覧です。

□ 要項の受験資格表で該当欄にチェックした
□ 試験日程一覧で支部・回・試験日・締切を転記した
□ 統一試験かCBTかを要項で確認した
□ 写真・勤務証明・卒業証明等を揃えた
□ 受験手数料を要項どおり納付した
□ 申込控え・領収書を保存した
□ 不受理通知がないか確認した

すべてにチェックが入ったら、学習は三領域の弱点演習に切り替えてください。申込の詳細手順は「申込手順と必要書類」で補完できます。

6よくある質問

申込締切はいつまでですか？
支部・回ごとに異なります。試験日程一覧で自分の受験回の申込期間を確認し、締切の7日前と前日にリマインドを登録してください。郵送申込は消印有効・必着など要項の定めが異なるため、投函は締切の2〜3日前を目安にしてください。電子申込は案内の時刻までに完了させてください。
締切直前に気づいた書類不備はどうすればよいですか？
要項記載の問い合わせ先で、締切内に修正・再提出できるか確認してください。写真サイズ・勤務証明の様式違いは不受理の典型です。間に合わない場合は次回の試験日程一覧で申込期間を登録し、今回分の書類を次回用に整えておくと二度手間が減ります。
締切後に学習はどう切り替えればよいですか？
申込完了後は、試験日から逆算した週次演習量に集中するのがおすすめです。三領域の通し演習を月2回入れ、領域別正答数で弱点を特定してください。足切りがある場合は要項の合格基準表を開き、記録票に領域別欄を必ず用意してください。計画の立て方は「学習計画の立て方」、合格ラインは「合格点・合格基準の見方」を参照してください。

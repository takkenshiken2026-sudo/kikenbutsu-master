危険物取扱者試験（乙4）の合格率の見方と演習得点への活かし方

合格率は受験者全体の結果であり、個人の演習得点をそのまま予測しません。乙4の合格基準は要項が正本で、50問・法令・物性・火災予防では科目別の足切りがある場合があります。本記事では消防試験研究センター（https://www.shoubo-shiken.or.jp/kikenbutsu/）の公表統計の確認先と、合格率を過信・悲観しない読み方、自分の通し演習の領域別正答数を学習計画に反映する手順を表にまとめます。数字は年度・種別で変わるため、古いまとめサイトの数値はそのまま使わないでください。

この記事の要点

本記事を読むと、乙4の合格率をどこで確認し、どう読めば学習計画に活かせるか（過信・悲観の両方を避ける）が分かります。

1合格率の確認先

合格率・受験者数・合格者数は、消防試験研究センターが公表する統計資料で確認します。消防庁は制度の概要確認に使い、試験結果の数字はセンター公表を優先してください。

| 情報 | 確認先 | 注意点 |
| --- | --- | --- |
| 合格率 | センター公表統計 | 年度・種別をメモ |
| 合格基準 | 要項「合格の基準」 | 合格率とは別 |
| 乙種第4類 | 第4類の表記 | 甲種・丙種と混同しない |
| 自分の得点 | 通し演習の記録 | 統計と直接比較しない |

確認時は「どの年度・どの試験回の数字か」を必ず書き留め、自分の受験年度と一致しているか照合してください。

2合格率と合格基準は別物

合格率30%前後だから自分の演習30%台なら同じ確率、とは単純には言えません。

| 指標 | 意味 | 学習での使い方 |
| --- | --- | --- |
| 合格率 | 全体の結果 | モチベーションの参考程度 |
| 合格基準 | 要項の正答ライン | 通し演習の目標 |
| 領域別正答 | 自分の記録 | 対策優先度の決定 |
| 足切り | 要項の表 | 1領域の極端な低さを潰す |

合格点・科目別基準の読み方は「合格点・合格基準の見方」で詳しく整理しています。2つの情報を混同しないよう、要項PDFは合格基準の章を別途ブックマークしてください。

3統計の読み方（過信・悲観を避ける）

公表統計は参考指標です。次の読み方が学習に直結します。

  • 年度比較：出題範囲改定の年は単純比較しない
  • 種別比較：甲種・乙種・丙種・第4類は別統計
  • 支部比較：受験者属性が異なる場合がある
  • 自分の模試：直近3回の通し得点の推移を優先

「みんな受かる／落ちる」という情報より、2週間ごとに演習記録を更新する習慣の方が、対策の具体化につながります。統計の細部は「合格率統計の読み方」も参照してください。

4演習得点への反映例

演習得点から次の一手を決める例です。

| 通し得点の目安 | 次の一手 |
| --- | --- |
| 25問未満 | テキスト該当章＋領域別10問/日 |
| 25〜35問 | 弱点1領域に週+5時間 |
| 35問以上 | 足切り確認＋誤答解き直し |
| 直前1か月 | 新規範囲停止、誤答・数字中心 |

三領域のうち2領域で過半数が取れていれば、残り1領域に時間を集中すれば合格圏に近づけます。配分と足切りは「出題科目・三領域と配分の見方」で要項確認してください。

5学習計画へのつなぎ方

合格率を見たら、最も正答率の低い領域に週30分を再配分してください。

1. 演習記録票に領域別正答数欄を用意する
2. 2週間ごとに弱点1領域を1つだけ選ぶ
3. その領域に演習20問＋用語10語を追加
4. 直前期は統計より誤答解き直しを優先

合格率は不安の増減に使わず、自分の伸びた論点・再発論点で週次計画を更新する方が安定します。週次の骨格は「学習計画の立て方」で試験日から逆算して書き込んでください。

6よくある質問

乙4の合格率はどの年度を見ればよいですか？
自分が受験する年度に最も近い、消防試験研究センター公表の最新統計を見てください。制度改定直後は前年との単純比較ができない場合があります。数字の正確さより、自分の通し演習の領域別正答数記録を優先し、統計はモチベーションの参考程度に留めてください。
合格率が低いと勉強時間を増やすべきですか？
総勉強時間より、足切りを下回る領域があるかを先に確認してください。再発している論点に絞って演習量を増やす方が、漫然と時間を増やすより効果的なことが多いです。合格基準は要項が正本であり、合格率だけで難易度判断しないでください。
合格率と自分の演習得点はどう付き合えばよいですか？
直接比較しないでください。合格率は全体、演習得点は個人の推移です。直近3回の50問通しで、総合正答数と三領域の正答数を並べて記録し、2週間ごとに弱点領域へ時間を移す運用がおすすめです。合格ラインの確認は「合格点・合格基準の見方」、統計の細部は「合格率統計の読み方」を参照してください。
